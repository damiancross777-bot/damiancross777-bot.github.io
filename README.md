# Phoneporium.AU website

Static site for Phoneporium.AU and GridRova (privacy policy, support, data deletion, app-ads.txt).
Pages are generated by `python3 build.py`; edit that file, rebuild, commit.

Custom domain: once `phoneporium.au` is registered, add a `CNAME` file containing `phoneporium.au`
and set the DNS records shown in Settings → Pages. Do not add CNAME before the domain is live.
